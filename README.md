# Design System Normalizer - Agui

运行在 Figma Desktop 内、以黑白中性色为主的本地规范绑定器。用户选择目标设计系统后，即可把生成稿的裸样式绑定为真实 Text Styles 与 Variables；VDesign 作为兼容预设保留，不再是插件唯一目标。

## 支持范围

- 目标规范：列出本地规范、团队变量库与 VDesign 预设，下拉选择即生效，无二次确认；没有本地资产的空候选禁用。
- 文字：使用目标配置在当前文件中可见的 Text Styles；VDesign 预设额外提供 35 个已发布 PingFang SC key。
- 颜色：先筛选精度合格候选再按节点语义消歧；开启近似匹配也优先使用精确候选，匹配包括透明度。
- 圆角与间距：通用配置读取对应 FLOAT Variables 的实际解析值；VDesign 继续使用验证过的发布 key 与 `resolvedPx`。
- 配置记忆：用户选择写入 `clientStorage`，当前文件选择写入文档 `pluginData`。
- JSON 规范包：在组件库源文件导出四类样式、变量集合/模式与组件清单；在目标文件导入后，文字样式与颜色/数值变量可作为匹配候选。组件、Paint/Effect/Grid Styles 当前只进入清单，不自动替换。

## 使用方式

1. 运行 `npm run build`。
2. 选择 `Plugins → Development → Import plugin from manifest...`，导入本目录的 `manifest.json`。
3. 在组件库源文件运行插件，点击右上角“导出”，在结果区下载 JSON；即使 Figma 未向插件提供文件 key，也会用资产 key 标识来源。原始 JSON 默认收起；若 Figma 未保存下载，可点击“复制”，必要时展开“查看原始 JSON”手动保存。保存或复制后点击摘要右侧“完成”，即可收起导出结果，保留当前配置与扫描预览。若源文件某个组件集有错误，其他资产仍会导出，界面和 JSON `warnings` 会列出未读取的组件属性定义。
4. 在要规范化的目标文件运行插件，点击右上角“导入”并选择 JSON 文件。导入会把该规范包存到当前用户的插件 `clientStorage`，并设为当前文件的目标规范；若有旧导出结果，导入成功后会隐藏。
5. 选中要处理的画板，选择规范类别，点击“扫描规范”，检查预览后点击“一键应用规范”。

不使用 JSON 时，可从下拉框直接选择本地规范、团队库或 VDesign 预设。导入的 JSON 不包含 Figma 资产本体；跨文件绑定需要当前账号能访问源库，且源资产拥有可导入的已发布 key。插件不会仅凭 JSON 重建整套组件库，也不会自动替换组件实例。

## 界面规范

- 控件按 shadcn 的 Alert、Field、Native Select、Toggle Group、Checkbox、Separator、Badge 和 Button 语义组合。
- 内容区左上角显示“设计规范绑定”标题；常驻选择/就绪提示隐藏，加载、操作结果与异常仍显示。
- 目标设计系统与目标字体同一行等宽排列，选择即载入且记忆，无二次确认区；首次打开通过占位项引导选择，不擅自启用推荐项。
- 导入/导出位于内容区右上角，不占用正文配置空间；导出后才显示摘要、缺项提示和下载/复制操作，原始 JSON 保持折叠。
- 导出区“完成”收起结果并恢复最近的主流程提示；复制失败保留原始 JSON 供手动复制，退出不重置目标或勾选项。
- 拖动窗口底部横向手柄调整高度（480–1040px），宽度保持 440px；手柄聚焦后可用 ↑/↓ 每次调整 40px，Home/End 跳到最小/最大高度。本次打开期间生效，重新运行恢复 760px；底部操作按钮固定，内容较多时正文滚动。
- 四类规范勾选项保持单行，不设外框，第一项与标题左对齐；标题与控件间距统一为 7px。
- 安全规则默认折叠，原有五项勾选状态不变；需要允许近似匹配或处理实例时再展开调整。
- 插件保持现有 Vanilla JavaScript 架构，不引入 React/Tailwind 运行时。
- 唯一视觉定制是所有组件圆角固定为 0；其余 hover、focus、disabled 与明暗模式沿用 shadcn 语义。
- 只有“应用完成”使用绿色，操作失败使用红色；初始化和扫描结果保持中性色。
- 安全选项勾选即生效；更改类别、字体、范围或保护规则会使旧预览失效，重新扫描后才能应用。
- 扫描说明区分实例保护、已有绑定、未匹配、候选缺失和变量读取/解析失败；节点数与属性数分别计数。已有绑定被保留不等于已经通过目标规范验收。

## 权限与凭证

- `manifest.json` 声明 `teamlibrary` 权限，用于读取当前文件已经启用且当前账号有权访问的团队变量库。
- 插件不需要 Personal Access Token，也不提供 Token 输入或存储入口。
- 插件禁止网络访问；它只能通过 Figma Plugin API 访问当前文件和已启用的团队设计库。
- 规范包可能包含样式名、变量值、模式和组件元数据；请按内部设计资料管理，不要公开分享敏感库的 JSON。

## 默认保护规则

- 默认只处理当前选择和可见节点。
- 默认保留已绑定的 Text Style、Paint Style 与变量，并跳过混合 Text Style。
- 默认保护组件实例及其内部属性。
- 文字默认只匹配相同字号。
- 颜色默认只绑定实际值完全相符的变量；近似颜色必须主动开启低置信度匹配。
- 0px 间距与 0px 圆角保持原值，避免为无意义属性制造大量绑定。
- 写入可通过 Figma 一次撤销。

## 设计系统配置

- 当前文件本地规范：只读取非远程 Text Styles 与 Variables。
- 已启用团队库：相同 `libraryName` 的多个 Variable Collections 合并为一个候选；文字使用文件中已可见的 Text Styles。
- VDesign 兼容预设：保留 35 个 Text Style key、9 个圆角和 11 个间距 Token，并动态读取已启用的 VDesign 颜色变量。
- 推荐不等于选择：只有一个已启用团队库时可标记“推荐”，用户从下拉框选择后直接载入；扫描在载入完成前禁用。

扫描变量时可能按需将用户选定库的 COLOR/FLOAT Variables 导入目标文件，以解析当前模式值；只有点击“一键应用规范”后才会修改节点绑定。规范包可跨文件复用，但不能绕过 Figma 的库访问权限。
