## 详细描述（可直接粘贴）

```
Design System Normalizer 把 Codex 或其他工具生成稿里的裸样式，绑定到用户确认的目标设计系统。插件会发现当前文件本地规范、已启用的团队变量库和 VDesign 兼容预设，但不会替用户决定目标。

功能
· 目标规范：按团队库分组列出候选，必须由用户确认后才能扫描
· 文字样式：使用当前文件可见的 Text Styles；VDesign 预设保留 35 个已发布 key
· 颜色变量：读取用户选定的变量库，以颜色值为硬约束、节点语义消歧
· 圆角与间距：按 FLOAT Variable 的实际解析值匹配；VDesign 使用验证过的兼容目录
· 配置记忆：同时记住用户常用选择与当前文件选择
· JSON 规范包：维护者可从组件库源文件导出样式、变量模式和组件清单，其他用户导入后作为目标规范；组件暂不自动替换

使用方式
1. 可在组件库源文件导出 JSON 规范包，并在目标文件导入；或在文件中启用需要使用的团队 Variable Library
2. 选中 Codex 生成的画板，运行插件
3. 导入 JSON 后会设为目标规范；其他候选需点击“设为目标规范”
4. 选择规范类别，点击“扫描规范”检查预览
5. 点击“一键应用规范”，写入可一次撤销

默认保护规则
只处理当前选择和可见节点；保留已绑定的样式与变量；跳过混合 TextStyle；0px 圆角与间距保持原值；组件实例内部属性默认不改。

权限与隐私
需要 teamlibrary 权限，只读取当前文件已启用且当前账号有权访问的团队库。插件禁止网络访问，不采集、不上传文件内容，也不需要 Personal Access Token。导入的 JSON 保存在用户的插件存储，目标规范 ID 会保存在插件存储和文档 pluginData 中；规范包可能包含内部样式与变量值，请自行控制分享范围。

适用范围
插件不能自动启用团队库，也不能通过公开 Plugin API 枚举未启用的组件库。JSON 只提供资产清单，真实绑定还需源库访问权限和已发布的资产 key；Paint/Effect/Grid Styles 与组件当前只进入清单，不做自动替换。没有 JSON 时，通用团队库的文字匹配依赖当前文件已可见的 Text Styles。
```
